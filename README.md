# 多维表格任务管理 · 使用说明

通过表格、看板、日历、甘特和画册管理任务，完成记录录入、人员分配、进度跟踪和日期安排。

## 1. 如何启动

### 环境准备

- 安装 Node.js 22 或更高版本，推荐使用 24 LTS。
- 使用近期版本的 Edge 或 Chrome 浏览器。

### 首次启动

在项目文件夹打开终端，依次运行：

```powershell
cd "C:\Users\admin\Documents\ChatGPT\SpreadJS Demo\feishu-datarange-demo"
npm ci
npm start
```

浏览器访问 **[http://localhost:5188/](http://localhost:5188/)**。保持终端开启，按 `Ctrl+C` 可停止服务。无需配置数据库或登录账号，请通过这个地址访问，不要直接双击 HTML 文件。

### 再次启动与更新

以后在项目目录运行 `npm start` 即可。更新项目后，先在原终端按 `Ctrl+C` 停止旧服务，再重新运行 `npm start`，最后刷新浏览器。

### 构建与预览

如需交付静态站点，运行：

```powershell
npm run build
npm run preview
```

`dist/` 包含完整的页面、应用代码和 SpreadJS 资源，可整体交给静态 Web 服务器托管。`preview` 默认也使用 5188 端口，运行前先停止已有服务，或设置其他端口。修改源码后需重新构建。

## 2. 第一次使用

当前浏览器尚无保存数据时，会自动载入三张示例数据表：**任务管理**（12 条任务）、**客户跟进**（8 条客户）、**内容排期**（8 条内容）。已有本地数据时，会恢复上次保存的工作区，包括之前保存的空表。

建议按下面的顺序体验：

1. 点击 **任务管理表**，浏览示例任务，了解执行人、进度、日期和重要紧急程度等字段。
2. 点击顶部 **添加记录**，填写必填的 **任务描述**，选择执行人、进度和日期，点击 **保存**。
3. 在表格中双击这条记录的单元格修改内容；点击左侧序号可打开完整详情。
4. 点击 **进度看板**，找到新增任务，将卡片拖到“已完成”列，观察任务状态和实际完成日期的变化。
5. 切换到 **任务日历** 或 **项目甘特**，查看同一条任务的日期安排。
6. 点击 **撤销** 或 **重做** 体验修改恢复；刷新页面，确认数据已经保存。

同一张数据表的各个视图共享记录。如果新增任务没有显示，先检查当前数据表、搜索和筛选条件，再检查日期所在的月份或时间窗口。

## 3. 核心功能罗列

| 核心功能      | 已实现的内容                                       |
| --------- | -------------------------------------------- |
| 记录管理      | 新增、编辑、删除、搜索记录；支持表格单元格编辑和详情面板编辑。              |
| 多视图展示     | 表格、看板、日历、甘特、画册五种类型，共享同一张表中的记录。               |
| 任务分配与进度调整 | 看板跨列拖动，修改执行人或任务状态。                           |
| 日期安排      | 日历拖动改期；甘特整体拖动及两端调整起止日期。                      |
| 字段配置      | 新增、编辑、删除字段，调整显隐、显示顺序、列宽、选项、默认值和数字格式。         |
| 字段类型      | 文本、数字、日期、单选、多选、人员、数值进度、评分、创建人和按钮；内置固定延期计算字段。 |
| 数据整理      | 关键词搜索、嵌套条件筛选、两级分组、两级排序；每个视图分别保存设置。           |
| 视图管理      | 新建、重命名、复制、删除视图，同一种类型可建立多个视图。                 |
| 数据表管理     | 新建、切换、重命名、复制、删除数据表，每张表独立维护记录、字段和视图。          |
| 日期联动与延期判断 | 任务完成时自动补充实际完成日期，并按状态、截止日期及实际完成日期计算延期结果。      |
| 本地保存与操作恢复 | 自动保存当前浏览器中的工作区；支持撤销、重做和恢复示例数据。               |

**任务管理**默认提供六个视图：任务管理表、进度看板、人员任务分配看板、任务日历、项目甘特、任务画册，其中两个看板属于同一种视图类型。**客户跟进**和**内容排期**各提供表格、看板、日历三个视图。

## 4. 视图切换与详细步骤

### 4.1 切换视图

1. 在左侧数据表列表中选择要操作的数据表。
2. 点击页面顶部的视图标签切换视图。
3. 在新视图中查看和修改记录，切回其他视图即可看到对应变化。

搜索、筛选、排序和分组设置按视图分别保存。例如，可以让一个看板只显示未完成任务，另一个看板只显示某位成员的任务。

### 4.2 任务管理表：录入和编辑

1. 点击 **任务管理表**。
2. 双击单元格，输入文字、选择人员或调整日期，结束编辑后写入。
3. 需要查看所有字段时，点击记录左侧序号，修改后点击 **保存**；点击 **取消** 放弃详情中的修改。
4. 点击分组标题可折叠或展开该组。
5. 通过顶部 **添加记录** 或分组内的新增入口添加任务。
6. 删除记录时，打开详情，点击底部 **删除记录** 并确认；误删后可在刷新前通过 **撤销** 恢复。

多选字段可按住 `Ctrl`（macOS 为 `Command`）选择多个选项。请使用应用提供的记录和字段入口进行增删操作。

### 4.3 看板：调整进度和分配人员

**调整进度：**

1. 切换到 **进度看板**，按任务状态查看卡片。
2. 点击卡片可打开详情。
3. 将卡片拖到另一列，任务状态随目标列更新。
4. 点击列头 `＋` 可在该列新增任务。

**分配人员：**

1. 切换到 **人员任务分配看板**。
2. 将任务卡片拖到目标成员所在的列。
3. 打开详情或切回表格，查看更新后的执行人。

看板也支持自定义分组；两级分组时，跨列拖动会写入目标列对应的两个分组值。

### 4.4 任务日历：安排任务日期

1. 切换到 **任务日历**。
2. 在日期字段下拉框中选择要展示的字段，例如“预计完成日期”。
3. 用 `‹`、`›` 切换月份，点击 **今天** 回到本月。
4. 将记录拖到另一天，修改当前选择的日期字段。
5. 点击某天右上角 `＋`，添加该日期的任务。
6. 当天记录较多时，点击 **查看全部 N 项** 打开完整列表；点击 **未排期** 查看尚未填写当前日期字段的记录。

### 4.5 项目甘特：调整起止时间

1. 切换到 **项目甘特**。
2. 选择开始日期字段和结束日期字段。
3. 用 `‹`、`›` 前后移动时间窗口，每次移动一周。
4. 拖动任务条中间部分，整体调整任务日期。
5. 拖动任务条左端调整开始日期，拖动右端调整结束日期。
6. 点击任务条可打开详情，查看或精确填写日期。

默认任务的预计完成日期不能早于开始日期，调整日期时需保持有效的起止顺序。

### 4.6 任务画册：浏览摘要

1. 切换到 **任务画册**，以卡片形式浏览任务。
2. 点击卡片打开详情，修改后点击 **保存**。
3. 点击 **字段配置**，调整摘要字段的显隐和顺序。

画册以状态颜色作封面。画册和看板均展示当前可见字段中靠前的四个摘要字段，主字段和按钮字段除外。

### 4.7 搜索、筛选、分组和排序

| 操作  | 详细步骤                                                                                    |
| --- | --------------------------------------------------------------------------------------- |
| 搜索  | 在右上角 **搜索记录** 输入关键词，按字段内容查找记录；清空输入即可取消搜索。                                               |
| 筛选  | 点击 **筛选 → 添加条件**，选择字段、比较方式和值，再点击 **应用**。可添加条件组，选择“全部满足 AND”或“任一满足 OR”；点击 **清除筛选** 移除条件。 |
| 分组  | 在表格或看板中点击 **分组**，选择第一层及可选的第二层字段，点击 **应用**。支持单选、人员和多选字段；选择“不分组”可取消。                      |
| 排序  | 点击 **排序**，选择第一、第二排序字段和各自的升降序，点击 **应用**。第一排序值相同时继续按第二字段排序；选择“默认顺序”可取消第一排序。               |

分组仅在表格和看板中启用。筛选支持等于、包含、大小比较、为空等条件，条件组可以嵌套。

### 4.8 配置字段

1. 点击工具栏 **字段配置**。
2. 勾选字段控制显示；拖动每行左侧的 `⠿` 手柄，或使用 `↑`、`↓`，调整当前视图的字段顺序（隐藏的字段也会保留原来的位置）。
3. 点击 **添加字段**，填写名称、选择类型，按需设置选项、默认值和列宽，点击 **创建字段**。
4. 点击字段旁的 `✎` 修改配置，再点击 **保存字段**。
5. 点击字段旁的 `×` 并确认可删除字段及其在整张表中的值；主字段不能删除。

字段名称、类型、默认值和列宽影响整张数据表；显隐和顺序只影响当前视图。更改类型会校验已有数据，转换失败时保留原值并提示原因。

| 配置项       | 使用说明                                             |
| --------- | ------------------------------------------------ |
| 单选、多选、人员  | 配置选项时用逗号分隔；人员使用本地示例成员。                           |
| 数字        | 可选择常规、整数、两位小数、百分比和人民币格式；百分比输入 `0.5` 显示为 `50%`。   |
| 日期        | 使用有效的 `YYYY-MM-DD` 日期。                           |
| 数值进度 / 评分 | 数值进度为 `0–100`；评分为 `0–5` 的整数。                     |
| 创建人       | 由系统填写示例创建成员；缺少信息的历史记录显示“未知（历史数据）”。               |
| 按钮        | 设置文字和动作：打开详情，或标记任务已完成。完成动作要求表中保留含“已完成”选项的任务状态字段。 |
| 是否延期      | 内置固定计算字段，只读，不支持改成自定义公式。                          |

默认表中的 **进度** 是任务状态，**完成进度** 是数值，两者独立。状态改为“已完成”时，若没有实际完成日期会自动填写当天；改回其他状态会清空实际完成日期，也可以在详情中手动填写。

延期按浏览器设备的本地日期判断：未完成且截止日期早于今天显示“已延期”；实际完成日期晚于截止日期显示“延期完成”；暂停任务显示“已暂停”。

### 4.9 管理视图和数据表

**管理视图：**

1. 点击视图标签行右侧的 **＋ 添加视图**，输入名称并选择类型，点击 **创建**。
2. 点击工具栏 **视图设置**，或右键当前视图标签。
3. 选择 **重命名**、**复制** 或 **删除**。删除视图会保留记录，至少需保留一个视图。

**管理数据表：**

1. 在左侧数据表列表中切换表；点击「数据表」标题右侧的 `＋` 新建空表。
2. 点击数据表标题右侧的 `⋯` 打开 **管理数据表**，也可以右键列表中的数据表。
3. 选择 **重命名**、**复制** 或 **删除**。复制会包含字段、记录和视图，后续分别编辑；删除会移除该表及其记录，至少需保留一张表。

### 4.10 保存、撤销和恢复示例

- **自动保存**：记录和配置保存在当前浏览器中。左下角显示 **保存在此浏览器** 表示保存正常。
- **撤销 / 重做**：点击工具栏按钮，或在结束单元格编辑并关闭弹窗后，使用 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。刷新后保留数据，但清空撤销历史。
- **恢复示例**：点击左下角 `↺` 并确认，重新载入 12 条示例任务。此操作会替换整个工作区，包括自己新建的数据表、记录、字段和视图，并清空撤销历史，无法通过撤销恢复。

浏览器数据按访问协议、主机和端口区分。`localhost`、`127.0.0.1` 和不同端口的数据各自独立；清除网站数据、使用隐私窗口或更换电脑可能无法找回原记录。当前应用没有云端备份或文件导出功能。

## 5. 常见问题

| 问题                 | 处理方法                                                     |
| ------------------ | -------------------------------------------------------- |
| 提示 `npm` 不是命令      | 安装 Node.js 后重新打开终端，再执行启动命令。                              |
| 提示端口已被占用           | 停止之前的项目服务，或按“如何启动”中的方法设置其他端口。                            |
| 更新后页面有按钮，但没有视图或记录  | 在原终端按 `Ctrl+C` 停止旧服务，重新运行 `npm start`，然后刷新页面。            |
| 没有看到示例数据      | 已有本地工作区时不会重新填入示例。先检查左侧数据表列表、视图和筛选；确需恢复时使用左下角 `↺`，注意会替换整个工作区。 |
| 提示缺少依赖或表格无法加载      | 在项目目录运行 `npm ci`，重新启动服务，再刷新页面。                           |
| 找不到刚新增的记录          | 清空搜索、清除筛选，确认当前数据表；日历检查月份和日期字段，甘特检查时间窗口。                  |
| 字段不能编辑             | “是否延期”“创建人”和按钮由系统或配置提供，普通字段可通过表格或详情编辑。                   |
| 修改日期失败             | 检查日期是否有效，以及预计完成日期是否早于开始日期。                               |
| 数值进度到了 100，但任务没有完成 | 数值进度与任务状态独立，需要将任务状态改为“已完成”。                              |
| 刷新后数据不同或又出现示例      | 检查是否更换浏览器、访问主机、协议或端口，或清除了网站数据。                           |
| 左下角显示“本次更改未保存”     | 检查浏览器是否禁止站点存储，或存储空间是否已满。                                 |
| 页面出现评估水印           | 当前使用 SpreadJS 评估版本；正式使用需配置匹配的商业许可证。                      |
